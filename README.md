# VietMath

VietMath is a free, lightweight, cross-platform mathematical equation editor focused on a polished experience for Vietnamese users while supporting multiple languages.

## Vision

Build a modern equation editor that is as close as practical to the core MathType experience:

- Visual mathematical equation editing
- LaTeX input and export
- Vietnamese-first, multilingual interface
- Windows and macOS support
- Word and PowerPoint integration
- Offline-first core experience
- Lightweight and optimized
- Free for end users
